<h1 align="center">create-jaab</h1>
<p align="center">Scaffold a <b>JAAB</b> blog, alone or beside docs, or add one to a repository you already have.</p>

```bash
npm create @jaamd/jaab@latest my-blog
```

This is [`@jaamd/create`](https://github.com/jaamd/jaamd/tree/main/packages/create)
with JAAB's templates: `blog`, the default, with the posts at `/`; and
`docs-blog`, with docs at `/` and the blog at `/blog`. Its options and its
`--here` mode are described there.
