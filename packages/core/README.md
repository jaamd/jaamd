# @jaamd/core

The framework-agnostic part of [JAAMD](https://jaamd.org): markup, markdown plugins, client-side enhancements, styles and themes.

Astro projects install [`@jaamd/astro`](https://www.npmjs.com/package/@jaamd/astro), which builds on this package.

The package ships TypeScript sources, compiled by the consumer's bundler.
