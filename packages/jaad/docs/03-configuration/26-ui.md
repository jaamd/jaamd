# `ui`

Replaces strings of the interface, by language. JAAD has its interface in
English and Italian, and picks it from each page's language: Italian docs need
no option.

| Type                                     | Default | Notes                          |
| ---------------------------------------- | ------- | ------------------------------ |
| `Record<string, Record<string, string>>` | `{}`    | Site option, JAAB reads it too |

## Use cases

### Wording of your own

Only the strings you set change:

```ts
ui: {
    en: { 'search.trigger': 'Find…' },
},
```

### A language JAAD has no strings for

Each string missing from the override is read in English. A language with
regional variants reads the base one too: `ui.pt` applies to `pt-BR`, and
`ui["pt-BR"]` wins over it.

```ts
ui: {
    pt: {
        'search.trigger': 'Pesquisar…',
        'page.copy': 'Copiar a página',
    },
},
```

To add a language to JAAD itself, see the
[translation guide](https://github.com/jaamd/jaamd/blob/main/CONTRIBUTING.md#translating-the-interface).

## The strings

Every key JAAD shows, with its English text. `{minutes}` and `{packages}` are
filled in. The `blog.*` keys are [JAAB](https://docs.jaamd.org/jaab)'s.

```ts
ui: {
  en: {
    "breadcrumb.label": "Breadcrumb",
    "feed.label": "RSS feed",
    "footer.credit": "Built with {packages}",
    "footer.label": "Site footer",
    home: "Home",
    "locale.change": "Change language",
    "nav.documentation": "Documentation navigation",
    "nav.mobile": "Toggle mobile menu",
    "nav.page": "Page navigation",
    "notFound.home": "Go back to the homepage",
    "notFound.text": "The page you're looking for doesn't exist.",
    "page.copied": "Copied!",
    "page.copy": "Copy page",
    "page.edit": "Edit this page",
    "page.lastUpdated": "Last updated on",
    "page.minutes": "{minutes} min read",
    "search.all": "All",
    "search.close": "close",
    "search.empty": "No results for",
    "search.label": "Search documentation",
    "search.loading": "Loading...",
    "search.navigate": "navigate",
    "search.open": "open",
    "search.placeholder": "Search documentation...",
    "search.results": "Search results",
    "search.sections": "Search in",
    "search.trigger": "Search docs...",
    "theme.toggle": "Toggle color theme",
    "toc.label": "Table of contents",
    "toc.title": "On this page",
  },
},
```

## Limits

The keys of a language are the ones above: a misspelt key stops the build.
Languages are tags, as `pt-BR`.
